# Agent / RAG 高频面试题

## 1. Agent 和 ChatBot 有什么区别？

回答要点：

- ChatBot 主要是单轮或多轮文本生成。
- Agent 以目标为中心，能规划、调用工具、观察结果、修正并完成任务。
- 工程上 Agent 需要状态管理、工具权限、trace、eval、失败恢复。

示例回答：

```text
ChatBot 的核心是根据上下文生成回答，而 Agent 的核心是围绕目标持续行动。比如企业数据分析场景，ChatBot 可能只能解释 GMV 是什么；Agent 会拆解任务，调用 SQL 查询 GMV 趋势，调用 RAG 查活动规则，再用 Python 做归因分析，最后生成带证据的报告。工程上 Agent 还要处理工具 schema、权限、安全、trace 和评测。
```

## 2. RAG 和微调怎么选？

回答要点：

- RAG 适合知识频繁变化、需要引用、企业私有知识。
- 微调适合风格、格式、特定任务能力对齐。
- 两者可以结合。

## 3. RAG 如何减少幻觉？

回答要点：

- 只基于检索上下文回答。
- 检索不到就返回资料不足。
- 引用溯源。
- 混合检索 + rerank。
- 评测 faithfulness 和 citation accuracy。

## 4. Chunk 怎么设计？

回答要点：

- 按标题和语义切，避免机械切断。
- chunk 太小语义不完整，太大噪声和成本高。
- 保留标题、来源、页码、权限 metadata。
- 用 eval 比较不同 chunk size。

## 5. Function Calling 的完整链路是什么？

回答要点：

```text
定义工具 schema -> 模型选择工具和参数 -> 后端校验参数 -> 权限校验 -> 执行工具 -> 返回 observation -> 模型总结或继续下一步
```

强调：模型不能直接执行真实操作，工具层是安全边界。

## 6. Agent 如何避免死循环？

回答要点：

- 最大步数限制。
- 最大重试次数。
- 状态中记录已尝试动作。
- Reflection 基于具体错误。
- 检测重复 action。
- 必要时请求人工介入。

## 7. Memory 怎么设计？

回答要点：

- 短期记忆保存当前会话和任务状态。
- 长期记忆保存稳定偏好和事实。
- 长期记忆写入要有判断和用户授权。
- 检索长期记忆也要做权限和相关性过滤。

## 8. 如何评估 Agent？

回答要点：

- 任务成功率。
- 工具选择准确率。
- 参数准确率。
- RAG Recall@k。
- 引用准确率。
- 延迟和成本。
- 安全违规率。

## 9. 如何防 prompt injection？

回答要点：

- 明确区分指令和数据。
- RAG 文档不具备修改系统指令的权限。
- 工具层做权限和参数校验。
- 敏感信息不暴露给模型。
- 高风险操作人工审批。
- 用攻击样本做安全评测。

## 10. MCP 是什么？

回答要点：

- MCP 是 Agent 连接外部工具和数据源的标准协议。
- MCP Server 提供 tools/resources。
- MCP Client 在 Agent 侧调用。
- 价值是工具标准化、复用、解耦。
