# 后端工程高频题

## 1. 高并发 Agent 服务如何限流？

要点：

- 用户级、租户级、接口级限流。
- 模型调用并发限制。
- 队列削峰。
- 超时和熔断。
- 降级到小模型或提示稍后再试。

## 2. 为什么需要消息队列？

Agent 长任务可能持续几十秒甚至几分钟。HTTP 请求不适合一直阻塞。可以把任务放入队列，前端轮询或通过 WebSocket/SSE 获取进度。

## 3. 数据库索引为什么能加速查询？

索引类似有序目录，能减少扫描行数。但索引也会增加写入成本和存储成本。高频查询字段适合建索引。

## 4. Redis 在 Agent 系统里怎么用？

用途：

- 会话缓存。
- 检索结果缓存。
- 模型响应缓存。
- 分布式锁。
- 限流计数器。

## 5. 如何设计幂等？

对可能重复提交的请求生成 `request_id` 或 `task_id`。服务端记录执行状态，重复请求直接返回已有结果，避免重复扣费、重复写入或重复发消息。

## 6. Agent 服务如何做超时？

- 模型调用超时。
- 工具调用超时。
- 整体任务超时。
- 节点级 timeout。
- 超时后返回结构化错误，允许重试或人工介入。
