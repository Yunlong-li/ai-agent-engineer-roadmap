# 可视化图谱 / Visual Maps

这里放可编辑学习图谱。优先使用 Mermaid，而不是直接生成图片，原因是：

- 架构图需要文字准确。
- Mermaid 可以随课程内容一起修改。
- 面试讲项目时可以直接复制到 README 或 PPT。
- 不依赖图片文件路径。

## 什么时候用 imagegen

适合：

- 课程封面。
- 学习路线海报。
- 概念类比插画。
- 项目演示封面图。

不适合：

- 需要精确文字的架构图。
- 需要经常修改的流程图。
- 代码结构图和系统设计图。

## 推荐策略

学习资料内部的核心图用 Mermaid；封面、海报、概念插画用 imagegen。这样既有视觉吸引力，也保留工程资料的准确性。
