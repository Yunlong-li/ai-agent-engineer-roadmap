# 简历项目 / Projects

简历项目建议只重点打磨 1 个主项目，再准备 1 个备选项目。项目不要堆技术名词，要能展示业务价值、架构能力、工程细节和评测结果。

如果你还没有完整搭过一个 Agent 项目，先按 [企业经营数据分析 Agent 实战教程](./agent-tutorial/) 从 0 到 1 跑通完整代码。教程会带你一步步实现 Schema、模拟数据、SQL Tool、RAG Tool、分析工具、Agent 编排器、FastAPI 接口和测试。
